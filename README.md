One Word From Grandma — the single word Grandma would text about AI: "Tinman". The Tin Man from The Wizard of Oz (1939): the robot Grandma actually knows. She does not say "AI", she names the walking, talking metal man from the film she grew up with — warm, a little baffled, funny in one word with no caption, unmistakably about a machine, and fresh instead of the field's crowded "Robit" / "Witchcraft" / "Doohickey". The program writes exactly those 6 bytes, no trailing newline, to /output/entry.txt.

## Run it

```sh
node main.ts
```
